## 0. 审阅入口：先比较方案，再确认规则

### 0.1 已明确的系统边界

个人单机使用；收盘后更新日线并生成信号；人工确认并在券商端下单。仅做 A 股股票的中期趋势跟踪，持仓可能持续数天至数月。只做多、使用自有现金。没有信号时允许持续空仓；没有最低交易频率要求。

Python 3.11 + Flask + 原生 JS/轻量图表库；行情数据以 hithink-finance CLI（同花顺数据服务，远端 API + 本地 DuckDB）为主路径，AKShare 为独立备选与核验路径（分工见 2.3 与 D10）；本地 parquet 策略缓存，支持增量更新和缓存新鲜度检查。Flask 在本机提供工作台页面，初版不涉及桌面安装包打包。

本文所有“建议值”均为研究起点，不代表实测最优参数，也不代表已经获得用户批准。除本节已明确的边界外，新增行为及默认值均随全文一起提交审阅。未经确认，不得进入实现阶段。

### 0.2 决策 D1：股票池

股票池的过滤方案与板块范围分别选择。不能把“全 A”悄悄解释成“只含沪深主板”。

| 方案 | 可交易候选范围 | 优点 | 缺点 | 建议 |
|---|---|---|---|---|
| U1 全 A | 当时已经上市且尚未终止上市的 A 股；保留 ST 与次新 | 覆盖广，可观察过滤对结果的影响 | 风险事件、无法成交和历史制度处理较复杂；次新容易缺少指标历史 | 作为对照方案 |
| U2 剔除 ST 与次新 | U1 中去掉当时的 ST、*ST，以及上市不足 120 个市场交易日的股票 | 降低特殊状态和早期上市交易带来的干扰 | 仍可能包含流动性不足的股票；会错过部分早期趋势 | 可用基础方案 |
| U3 增加流动性过滤 | U2 + 最近 20 个市场交易日日成交额中位数不低于 5,000 万元，且至少 18 日有实际交易 | 执行更接近个人交易条件，降低冷门股票对结果的影响 | 覆盖率下降；无法消除涨跌停和突发流动性风险 | **推荐起点** |

所有方案都遵守上市状态、账户板块权限、数据完整性、指标预热、当日停牌和可成交检查。U1 保留次新身份，并不意味着没有历史数据也能计算 120 日均线。

流动性阈值比较建议：3,000 万／5,000 万／1 亿元；选择后固定，先比较覆盖率和无法成交率，再比较收益。这里不给未经回测的覆盖股票数。

**板块范围待确认：**建议首版只启用沪深主板，股票列表保留全部板块信息；创业板、科创板、北交所分别作为显式开关，获得用户确认、具备账户交易权限及相应历史制度数据后启用。若用户选择覆盖沪深京全部 A 股，第一阶段的制度和数据验收范围随之扩大，不得仍以主板测试替代。

**历史覆盖降级决策（待确认，随 D11）：**无论主备数据源，历史退市股行情、历史 ST 状态与公告时间均难以完整获得。首版回测接受“存续股回测”口径：股票池仅含评价期内存续且数据可得的股票；报告中必须以显著位置披露存活偏差及其方向（对趋势跟踪通常为高估收益、低估退市与风险警示损失），并把“严格含退市全 A 回测”列为 v2 目标，不作为首版验收门槛。可获取的退市与 ST 数据尽力覆盖，缺口如实记录，不虚构、不用当前名单冒充历史名单。

### 0.3 决策 D2：趋势与进场逻辑

以下频率与换手描述是规则结构推断，不是实测排序。比较时必须使用同一股票池、回测区间、费用、仓位约束和成交模型；交易次数最终还受出场及重新进场规则影响。

| 方案 | 趋势条件与买入信号 | 趋势出场 | 信号频率／换手倾向 | 震荡市表现与代价 |
|---|---|---|---|---|
| A：Donchian 突破 | 收盘价超过**此前** 55 根有效 K 线最高价，且高于 SMA120 | 收盘价低于此前 20 根有效 K 线最低价 | 趋势初成时发出；连续创新高时可持续满足条件，但持仓期间不重复买入；较短通道通常更活跃 | 横盘上沿可能反复出现假突破；启动识别较清楚，但往往买得较高 |
| B：双均线 | SMA20 从不高于 SMA60 变为高于 SMA60，且收盘价高于 SMA60 | SMA20 不高于 SMA60 | 只有交叉事件发信号；20/60 参数下通常不会每日触发；强趋势中换手偏低 | 均线粘合区反复交叉；识别与出场均有滞后，止损后可能很久没有新的交叉 |
| C：ADX + 均线 | 收盘价 > SMA60、SMA20 > SMA60、ADX14 ≥ 25、+DI14 > −DI14，四条件整体从不成立变为成立 | 收盘价低于 SMA60 连续 2 根有效 K 线，或 SMA20 不高于 SMA60 | 强度过滤减少一部分入场，但 ADX 阈值来回切换也会产生事件；不保证交易次数必然最低 | 可过滤部分弱震荡，强烈来回波动时 ADX 仍可能较高；参数和解释成本更高 |

**建议首版选 A。**理由是突破基准、信号时间和出场条件较容易逐根核对。B 适合作为简单对照；C 在基础流程可靠后有比较价值。三者初版只选一套用于正式信号，不做三套投票，也不择时切换策略。

不提供“预计年化”“预计胜率”等数值，因为尚未进行满足本文口径的回测。

### 0.4 决策 D3：初始止损、移动止盈与时间止损

| 组件 | 候选 | 优点／代价 | 建议值 |
|---|---|---|---|
| 初始止损 | 入场成交价 − m × 信号日 ATR20 | 适应波动；高波动股票的止损幅度可能很宽 | m = 2.5；比较区间 2～3 |
| 初始止损 | 入场成交价 × (1 − f) | 直观；相同百分比对不同股票的约束强弱不同 | f = 8%；比较区间 6%～10% |
| 移动止盈 | 持仓最高收盘参考价 − 3 × 当日 ATR20，只上移不下移 | 保留趋势空间；利润可能回吐；名称不表示一定有利润 | 开启，从入场日收盘开始计算 |
| 时间止损 | 入场满 20 个市场交易日，最大收盘有利变动仍不足 1R | 淘汰长期没有进展的持仓；可能错过较晚启动的趋势 | **默认关闭**，保留独立开关 |
| 趋势出场 | 与 A/B/C 配套的趋势出场 | 结束已失效的趋势，存在滞后 | 开启 |

**推荐组合：ATR 初始止损 + ATR 移动止盈 + 配套趋势出场；时间止损关闭。**ATR 与固定比例是互斥的初始止损方案，不把两个初始止损隐含叠加。

本系统使用**收盘确认止损**：T 日收盘满足条件，最早在 T+1 执行。盘中低点触线但收盘收回，不触发该收盘规则。若希望盘中触线即卖，属于执行方式变更，必须重新确认并增加相应数据和成交规则。

### 0.5 决策 D4：仓位管理与大盘调节

| 方式 | 数量依据 | 优点 | 代价 |
|---|---|---|---|
| ATR 风险预算制 | 允许的单票计划风险金额 ÷ 每股初始止损距离，再受资金和数量约束 | 止损较远时自动少买；不同股票初始风险更接近 | ATR 不是最大亏损保证；整股约束会使预算无法用满 |
| 等权制 | 每次新建仓以账户权益的 10% 为目标，再受同样风险约束 | 易解释、易核算 | 高波动股票可能需要缩量；实际仓位因此不一定相等 |

**建议风险预算制：**单票计划风险占账户权益的 0.5%；供用户选择的研究区间 0.25%～0.75%。1% 只列为提高风险的独立比较情景，不作为默认。计划风险不包含隔夜跳空、无法成交及费用，实际亏损可能超过预算。

建议同时采用：单次建仓市值不超过权益 10%，最多 10 只股票，全部持仓的剩余初始风险额度合计不超过权益 4%。行业初版只展示，不作为仓位过滤；需要行业限额时须补齐历史行业分类并另行确认。

| 大盘状态 | 定义引用 | 建议总仓位目标上限 | 行为 |
|---|---|---:|---|
| 牛 | R12 的指数条件 | 80% | 在约束内接受新买入 |
| 震荡 | R12 的指数条件 | 30% | 在约束内接受新买入 |
| 熊 | R12 的指数条件 | 0% | 停止新买入，生成存量持仓退出意图 |
| 未知 | 指数数据不完整或未预热 | 不产生新目标 | 阻止新买入；维持已有退出意图，仍检查可计算的个股出场 |

指数建议使用沪深300官方历史价格指数，代码以“指数身份 + 市场”保存，避免与同代码股票混淆。它只是大盘状态代理，不能代表每个板块行情。

总仓位目标是约束，不是必须买满的任务。目标上限下降时立即生成减仓意图；其余日期容许 5 个百分点的价格漂移，超过后减至目标上限。熊状态不设漂移容忍。实际无法卖出时允许实际仓位超标，但必须显示超标及原因。

### 0.6 决策 D5：卖出裁决

建议优先级：**资格退出 → 初始止损 → 移动止盈 → 趋势出场 → 时间止损 → 大盘减仓**。同一股票只生成一个合并退出意图，保留全部触发原因，并以最高优先级作为主原因。优先级不代表不同的成交价格：所有规则均遵守下一交易日开盘执行口径。

卖出执行前还须检查能否成交。停牌、开盘跌停、不可卖数量和数据缺失是执行阻断，不是低优先级规则。

## 1. 术语表与符号

本文策略概念、数据概念和绩效名称只使用本节列出的术语；普通中文及技术栈专名不作为新增策略术语。伪代码的中间量必须在对应规则输入或赋值处定义。`>`、`<` 是严格比较，`≥`、`≤` 包含相等；区间端点包含在内，另有说明除外。

### 1.1 时间、价格与数据

| 术语／符号 | 唯一定义 |
|---|---|
| A 股、股票身份 | 沪深京市场以人民币交易的普通股票；身份为交易所 + 证券代码 + 上市生命周期，不含 B 股、ETF、存托凭证或可转债 |
| 板块权限 | 用户明确确认可交易的板块集合，独立于数据是否能够获取 |
| 市场交易日 | 交易所交易日历中的开市日；不是自然日 |
| T、T+1 | T 为生成信号所对应的完整市场交易日；T+1 为其后第一个市场交易日，即使该股票当天停牌也不改变此定义 |
| 信息截止时点 | 北京时间 T 日 18:00；固定同一时点以保持回放一致性，时点后新公布信息不能补写进原信号 |
| K 线、OHLC | 一只股票一个市场交易日的开盘价 O、最高价 H、最低价 L、收盘价 C，满足 L ≤ min(O,C) ≤ max(O,C) ≤ H；无真实成交时不造 K 线 |
| 有效 K 线 | 有实际成交且通过数据校验的一根日 K 线；指标窗口默认按有效 K 线计数 |
| 原始价格 | 未复权的实际交易价格，记为 Oraw、Hraw、Lraw、Craw，单位元/股 |
| 前复权价格 | 把历史原始价格按截至指定时点已生效的权益事件变换到该时点价格尺度的价格；本文指标价格 O、H、L、C 均指这一口径 |
| 复权基准 | 前复权价格所对齐的时点；T 日指标的基准为 T，历史回放不能自动使用今天的基准 |
| 复权变换 | 同一股票两个复权基准间经验证的正向变换 P新 = a × P旧 + b，a > 0；距离乘 a，不能简单用价格比替代含 b 的变换 |
| 成交量 V、成交额 A | 当日实际成交股数、人民币金额；缓存统一为股和元，不对二者做价格复权 |
| 停牌 | 官方状态表显示暂停交易；不能以下载失败或 V=0 单独推定 |
| 一字涨停／一字跌停 | 有真实交易且原始 OHLC 全部等于当日官方涨停价／跌停价；价格相等按最小价位校验 |
| 涨停价／跌停价 | 对指定股票、日期依法生效的最高／最低可交易价格；无涨跌幅限制日不设此值 |
| ST 状态 | 某时点生效的风险警示状态，包含 ST、*ST；摘帽是状态取消，戴帽是状态生效 |
| 次新 | 从上市首日至 T 已经历的市场交易日数不足 120；上市首日计 1 |
| 慢变量 | 财务、股本、行业、上市状态等非每日行情数值，按公开时间与生效时间取当时可用版本 |
| 公开时间／生效时间 | 信息首次对市场可获得的时间／其内容开始适用的时间，二者分开保存 |
| 数据快照 | 一次运行使用的不可变数据集合及其来源、版本、获取时间、复权基准和校验摘要 |
| 缓存新鲜度 | 缓存所覆盖的完整市场交易日和所需状态信息是否达到本次目标 T；不以文件修改时间替代 |
| 未知／不可计算 | 缺少必需数据、存在未解决冲突或指标未预热的状态；不等于条件不成立或无信号 |
| 预热 | 为得到规则需要的全部当前值与滞后值而加载、计算但不评价绩效的历史区间 |
| 防未来数据泄漏 | 信号与决策只访问其时点已可获得的记录；执行函数只额外访问执行时点允许的信息 |
| 存活偏差 | 以今天仍存续或今天仍符合过滤条件的股票代替历史当时的股票池造成的偏差 |
| 前缀一致性 | 截断到 T 运行所得的 T 日信号，与在完整历史上限制信息至 T 运行的结果一致 |
| 枢轴点 p | 以有效 K 线 p 为候选，需检查其左侧及右侧指定根数 K 线才能认定的局部极值 |
| p+k 延迟确认 | 需要右侧 k 根有效 K 线的枢轴点，最早在第 p+k 根收盘后确认，随后下一市场交易日才可执行 |

### 1.2 指标、信号与账户

| 术语／符号 | 唯一定义 |
|---|---|
| SMA n | 最近 n 根有效 K 线收盘价的算术平均，含当前根；无足够 n 根时不可计算 |
| Wilder 平滑 W n | 初值为前 n 个有效输入的算术平均；随后 Wt = ((n−1)Wt−1 + xt)/n |
| TR | max(H−L, abs(H−前一有效收盘), abs(L−前一有效收盘))，所有输入须在同一复权基准 |
| ATR n | TR 的 Wilder 平滑；第一根没有前收盘的 K 线不提供 TR |
| +DM／−DM | 向上／向下的有效价格扩张；精确定义见 R06；同幅扩张时二者均为 0 |
| +DI n／−DI n | 100 × Wilder 平滑后的 +DM／−DM ÷ ATR n；ATR=0 时均为 0 |
| DX n、ADX n | DX=100×abs(+DI−−DI)/(+DI+−DI)，分母为 0 时取 0；ADX 为 DX 的 Wilder 平滑 |
| Donchian 上轨 U n／下轨 D n | 当前根**之前** n 根有效 K 线最高价的最大值／最低价的最小值，不包含当前根 |
| 趋势条件 | A/B/C 所定义的、截至当前收盘支持持有上涨趋势的布尔条件，不作价格预测 |
| 交叉事件 | 当前条件成立、前一有效 K 线条件不成立；前一值未知时不生成事件 |
| 买入信号 | 某条进场规则在 T 日成立的记录，尚未等同于获准订单或实际买入 |
| 出场信号 | 某条持仓退出规则成立的记录；即使暂不能成交也保留 |
| 资格退出 | 持仓发生 ST 戴帽、进入退市整理、终止上市公告确定、板块权限取消等本文列明事件所产生的退出要求 |
| 交易意图 | 由信号及仓位规则生成的拟买卖方向、数量上限、有效期、规则原因和数据快照记录 |
| 持续退出意图 | 对剩余持仓持续有效的卖出要求，受阻后每天重试；不因后续价格反弹自动取消 |
| 成交回报 | 用户录入或导入的真实成交日期、时间、数量、价格、费用；模型回测中为执行模型生成的对应记录 |
| 入场日 e、入场价 P | 首次买入实际成交的市场交易日及不含费用的成交价；一只股票只允许一轮持仓，不加仓 |
| 现金、应收权益、股票市值 | 可用于买入的人民币余额／已取得权利但未到账的现金或股份价值／原始收盘价乘已到账持股数 |
| 账户权益 E | 现金 + 应收权益 + 股票市值 − 已确认负债；无外部存取资金的回测中用于净值计算 |
| 计划账本 | 在T日按当日原始收盘价和适用费用估计拟退出后的现金、持仓与风险余额，仅用于分配次日订单上限；不改变真实账户或回测账户实际余额 |
| 开盘估值权益 | 执行时以当日已知原始开盘价对持仓估值，加现金和应收权益、减负债；停牌沿用经权益事件转换的最后可信价；不使用当日收盘价 |
| 初始止损 S0 | 入场价减每股初始止损距离；建立后只因复权基准变化进行等价变换，不因新 ATR 放宽 |
| 每股初始止损距离 d、1R | 入场价与 S0 的差，必须大于 0；1R 即该距离，不是 1% |
| 计划风险 | 拟成交或剩余股数 × 对应的每股初始止损距离，不含跳空、费用和无法成交风险 |
| 剩余初始风险额度 | 当前剩余股数 × 入场时 d 的等价转换值；不因移动止盈上移而释放，退出后才减少 |
| 单票风险比例 r | 单票允许计划风险 ÷ 信号日账户权益，推荐 0.005 |
| 持仓最高收盘参考价 HC | max(入场价、入场日至当前日所有有效收盘价)，全部换算到当前复权基准 |
| 移动止盈 M | max(S0、上一日 M 的等价转换值、HC−3×当日 ATR20)，不下调 |
| 最大收盘有利变动 MFE_R | (HC−入场价的等价转换值)/当前基准下的 d；衡量是否曾在收盘达到 1R |
| 持有天数 h | 入场日至当前日的市场交易日数，入场日计 1，停牌日计数 |
| 时间止损 | 已启用且 h≥20、MFE_R<1 时产生的出场信号 |
| 冷却期 | 完整卖出后暂停新买入信号转订单的 5 个市场交易日；不含卖出日 |
| 总仓位 W | 股票市值加应收股份市值，占账户权益的比例；应收现金不计入股票仓位 |
| 大盘状态 | 指数收盘与 SMA200 及其 20 个市场交易日前的值确定的牛／熊／震荡／未知状态 |
| 强度分数 Z | (当前 C−SMA60)/ATR20；用于固定排序，不用未来收益；不可计算的既有持仓在减仓排序中排最弱 |
| 资格过滤 | 是否允许新建仓的判断；流动性下降或不再满足进场条件不自动等同于资格退出 |
| 最小价位 | 当前适用的申报价格最小变动单位；普通 A 股为 0.01 元，历史按制度表读取 |
| 数量取整 | 不向上增加数量，取不超过计算上限且满足当时板块买入申报规则的最大整数股数 |
| 开盘执行模型 | 在 T 固定排序和数量上限，T+1 以原始开盘价和固定滑点模拟执行，不使用当日后续高低收决定开盘订单 |
| 佣金／印花税／过户费 | 按 R18 约定分别计算的券商服务费用／卖出税费／成交登记过户费用 |
| 滑点 s | 买入成本相对原始开盘价向上、卖出成交价向下的不利偏移比例，推荐每边 0.0005 |
| 基点 bp | 0.01%，即 0.0001；5bp=0.05% |
| 健康度 | “数据待核、退出受阻、待退出、临近出场、趋势维持”五种确定状态，按 R24 优先级显示，不表示上涨概率 |

### 1.3 回测与验收

| 术语 | 唯一定义 |
|---|---|
| 规则回测 | 假定所有合法交易意图均按执行模型执行的账户历史；不混入用户事后取舍 |
| 实际账户记录 | 由真实成交回报形成的持仓和权益记录，与规则回测分别展示 |
| 历史回放 | 将信息截止时点移动到历史 T，逐日展示当时可知的股票池、信号、交易意图和持仓 |
| 完整交易 | 一只股票从首次买入至全部卖出的持仓周期；没有完全退出不纳入胜率和盈亏比 |
| 交易净盈亏 | 退出所得 + 归属该交易的净权益分派 − 买入支出 − 所有交易费用，滑点已体现在成交价中 |
| 日收益 r_t | 无外部存取资金时 E_t/E_t−1−1；t 为每个市场交易日 |
| 净值 N_t | E_t/E_0，N_0=1，包含现金、费用及未实现盈亏 |
| 年化收益 CAGR | (E结束/E开始)^(252/n)−1，n 为实际纳入评价的市场交易日收益个数 |
| 最大回撤 MDD | max_t(1−N_t/max_{0≤u≤t}N_u)，以非负比例报告 |
| 胜率 | 交易净盈亏>0 的完整交易数 ÷ 全部完整交易数，零盈亏计入分母但不计为胜 |
| 盈亏比 | 盈利交易的平均净盈利 ÷ 亏损交易的平均净亏损绝对值，按人民币金额统计 |
| 换手 | 日换手=(当日买入成交额+卖出成交额)/(2×前日账户权益)；累计与年化分别见 R21 |
| 卡玛比 | 年化收益 ÷ 最大回撤；使用完全相同的评价区间和费用口径 |
| 分层统计 | 按上一交易日可知的大盘状态归属当日账户收益；完整交易另外按入场前信号日状态归组 |
| 样本内／样本外 | 用于规则或参数选择的时间段／事先保留且不用于选择的时间段，必须按时间顺序切分 |
| 合成 K 线用例 | 人工构造且数值公开的 OHLC 与必要状态，用于手算验证规则；不是历史业绩证据 |
| 阶段验收 | 指定阶段的功能、合成用例和失败处理通过后才进入下一阶段；验收不等于策略具有盈利能力 |

## 2. 数据口径与数据层要求

### 2.1 两种价格用途必须分开

指标、信号及图表默认使用前复权日线；订单撮合、涨跌停、最小价位、交易费用、现金和持股账本使用原始价格。任何记录都须写明价格口径和复权基准。T 日价格基准下，T 日前复权收盘与 T 日原始收盘一致。

任何数据源（AKShare、hithink-finance 的 forward 复权等）返回的前复权历史都会随权益事件而变化，部分口径还可能出现历史负值。因此不能把今天下载的整段前复权价格直接视为当年当时所见数据；主路径按 2.3 用原始 OHLC + 复权因子本地重建各时点前复权视图。[AKShare 股票数据说明](https://akshare.akfamily.xyz/data/stock/stock.html)

建议缓存原始 OHLC、权益事件及可验证的复权变换；为每个回放 T 构建截至 T 已生效的前复权视图。外部前复权序列可用于交叉核验，不能省略时间版本。复权方法不一致时不逐日拼接两家前复权价格。无法重建或验证时，相关严格回测中止并报告，不能偷换为最新复权结果。

### 2.2 数据记录的最小信息

| 类别 | 必需信息 |
|---|---|
| 股票列表 | 股票身份、代码、交易所、板块、上市日、终止上市日、名称历史、状态有效期；必须覆盖历史退市股票 |
| 日线 | 日期、原始 OHLC、成交股数、成交额、当日价格限制参考价、涨跌停价或可验证的制度计算依据 |
| 交易日历 | 交易所、市场交易日、是否开市；不以周一至周五推定 |
| 状态历史 | 停复牌、ST 摘戴、退市整理、无涨跌幅限制状态，含公开时间和生效时间 |
| 权益事件 | 公告与修订版本、股权登记日、除权除息日、现金到账日、股份到账及可卖日期、分配比例、复权变换依据 |
| 复权因子 | 事件日期、因子值、来源与版本；与权益事件一一对应，用于本地重建各基准前复权视图 |
| 指数 | 沪深300原始历史 OHLC、日期、来源；不使用今天成分股重算历史指数 |
| 行业 | 来源分类名称、分类版本、公开时间、生效时间；没有历史版本时只显示当前行业，不能用于历史选股或归因 |

主路径采用本机已部署的 hithink-finance CLI（同花顺数据服务：远端 API + 本地 DuckDB 库 + 质量校验）。下表能力于 2026-09-06 经 `hithink-finance capabilities` 实测确认，第一阶段仍须对目标区间复验。

主路径接入约定：远端下载与质量门禁统一经 CLI 的 `data init / data sync / data validate` 完成；策略层不直接调用远端，只读经校验的本地库并导出为 2.5 约定的按股票身份和年份的 parquet 策略缓存。CLI 依赖 API Key 且为远端商业服务：Key 失效、服务变更或网络失败时按备选路径降级，切换必须保留来源记录。数据快照必须记录 CLI 版本、`data validate` 结果与导出时间。

### 2.4 停牌、缺失、一字板、ST

停牌日保留日历与状态，不复制前收盘造有效 K 线；价格指标跳过停牌日，持有天数和上市天数照常累加。流动性窗口按市场交易日，已确认停牌日成交额记 0。价格缺失但没有停牌依据时为数据缺失，不能当成停牌或零成交。

停牌持仓以最后可信原始价格及已生效权益事件估值，并标明估值滞后。不能因停牌从账户里移除仓位，也不能记作零风险。

一字板按原始价格和当日价格限制核验。是否能在开盘成交只使用开盘时已知信息；不使用当日是否后来开板来决定开盘成交。

U2/U3 从 ST 生效日起禁止新买入；已知在 T+1 生效的戴帽公告，在 T 截止时点已公开时就取消次日买入。持仓戴帽产生资格退出。摘帽从实际生效日恢复资格，不回改此前历史；仍须重新满足进场及冷却期。初版 U1 即使允许买入 ST，持仓期间新发生戴帽或升级为 *ST 仍产生资格退出，此保守行为属于待确认的统一规则。

### 2.5 增量缓存与新鲜度

推荐按股票身份和年份保存原始日线 parquet，状态与权益事件另表，衍生指标按参数版本保存。每次从已缓存末尾向前重叠 20 个市场交易日请求，去重并检测修订；首次下载覆盖评价期之前的完整预热需求。

权益事件、历史修订或复权基准变化时，不能只在旧前复权文件尾部拼接新 K 线：重建受影响区间的前复权视图和衍生指标，并为新结果生成新版本。旧信号快照保留不覆盖。网络失败保留上次成功缓存；新批次完成校验后才整体替换，防止半写入。

T 日 18:00 后也不假设源一定更新完成。只有目标股票池的必需日线、指数、状态、权益事件均满足目标 T，才发布可执行的新买入清单。停牌股票有可信当日状态即视为状态覆盖；下载失败不能从分母删除。若股票池有未解决的数据缺口，全局买入排序不发布；对数据完整的已有持仓仍可发布出场提醒。旧数据可以浏览，但必须显示旧日期与“未完成更新”。

## 3. 防未来数据泄漏纪律

1. **指标输入：**价格、量、额的最大日期为 T；`U55`、`D20` 必须排除 T；不使用负向移动、居中窗口或未来补值。
2. **两个时间：**慢变量同时满足公开时间不晚于信息截止时点、生效时间不晚于适用时点。财报以公开时间而非报告期末进入系统；更正值在更正公开前不可用。首版范围（D11）：本策略 A/B/C 不使用财报类慢变量，本条的双时间戳机制在引入财报因子前只需实现 ST／退市／停牌等状态类；状态类无公告时间字段时按第 3 条保守延迟处理。
3. **只有日期没有时分：**不能假装公告在开盘前公开。建议从该日期之后第一个市场交易日的信号计算起使用；明确记录这一保守延迟。停牌、ST 等执行状态另需在执行时点核验。
4. **复权版本：**历史 T 只使用截至 T 已生效的权益事件。晚于 T 的分红或拆股不得改变历史 T 的原始信号记录。历史更正生成“修订数据回放”新版本，不能冒充当时实际已知。
5. **枢轴点：**需右侧 k 根确认时，候选点日期 p 与确认日期 p+k 分别保存；图表允许把候选位置画在 p，但必须同时显示确认时间。参与交易的日期只能从确认后的下一市场交易日开始。
6. **股票池：**每个 T 按历史上市、退市、ST、流动性和板块状态重建；不得从今天的股票列表或今天的行业分类倒推全部历史。
7. **执行隔离：**T+1 开盘价只能用于已存在交易意图的成交、取消、缩量与费用计算。不能反向修改 T 的信号、排序、参数或提高数量上限；T+1 的 H/L/C/V/A 不得参与开盘决策。
8. **分层统计：**当日收益按 T−1 已知的指数状态归属；不能用事后峰谷标记来决定当日仓位。
9. **参数选择：**记录每次比较的参数和结果。参数只在样本内选择，样本外不得看完结果再修改并仍称为原样本外。
10. **断言：**每个输入带可用时间；执行“未来追加不改变过去信号”“截断回放一致”“晚公告不提前生效”“未来权益事件不重写过去信号”“T+1 高低收变化不影响该日开盘决策”的验收。

缺乏历史状态、退市数据或权益事件时，可以运行带明显缺陷标识的探索性报告，但不能输出“严格历史全 A 回测通过”的结论。是否接受该降级必须问用户，不自行更改资格。

## 4. 规则目录、伪代码与合成 K 线用例

### 4.0 用例约定

每条编号规则都附有输入、说明性伪代码及人工预期。短窗口用例只缩短该用例的参数，生产建议参数不变。`[O,H,L,C]` 为一根 K 线；未给定的身份状态默认普通沪深主板、非 ST、非停牌、无权益事件、已获板块权限；成交类用例另列价格限制。除R18及明确写出费用/滑点的用例外，合成用例的交易费用与滑点均设0，以隔离所验证规则；R03的股息税假设仍按该用例执行。这些测试覆盖值不改变正式费用默认值。

`F(x)` 表示 `[x,x,x,x]` 的有效 K 线，V=100 万股，A=x×100 万元；平价日不自动是一字涨跌停，必须同时等于官方涨跌停价。`连续 n 根 F(x)` 是精确重复的合成序列，可以手工展开。仅说明指标的用例不启用不相关的股票池或账户约束。

### R01 数据校验、新鲜度与发布门槛

伪代码：

```text
确定目标 T = 当前时间已经越过信息截止时点的最近市场交易日
对股票池每只股票：
  若官方停牌：保留状态，流动性成交额 = 0，不造有效 K 线
  否则要求原始 OHLC 有限且大于 0、顺序正确、V > 0、A > 0、日期唯一
  要求当前策略窗口前复权 OHLC 大于 0，且来源、单位、复权基准已确认
  要求状态、权益事件和制度数据覆盖 T
若任何必需输入缺失或冲突：禁止发布全局新买入排序
已有持仓按各自数据完整性继续产生可计算的出场提醒
```

用例：T−1=`[10,10.5,9.8,10.2]`；T 无 K 线。若 T 官方停牌，则缓存记录停牌、有效 K 线数量不增加；若没有停牌记录，则 T 数据缺失，不能生成 T 的新买入清单。另一股票 T=`[10,9,8,10]`，因 H<O 且 H<C，拒绝。周五数据完整、周六运行，目标仍是周五，不因周末判过期。

### R02 资格过滤与流动性

伪代码：

```text
基础资格 = T 时点已上市、未终止上市、板块允许、T 有效 K 线、状态完整
若 U2 或 U3：要求非 ST、非 *ST、上市市场交易日数 ≥ 120
若 U3：
  取最近 20 个市场交易日成交额，官方停牌日填 0，数据缺失不填 0
  要求中位数 ≥ 50,000,000，且 V > 0 的日期数 ≥ 18
要求所选进场规则及仓位排序指标已经预热
只对新买入应用资格过滤，不删除既有持仓
```

用例：连续 20 个市场交易日 OHLC 均为 `F(10)`；其中 18 日 V=600 万股、A=6,000 万，2 日为官方停牌无 K 线、A=0。中位数=6,000 万、实际交易日=18，上市第120日且非 ST 时通过 U3；第119日不通过。改成17日实际交易、3日停牌，则交易日数不通过。最后一日成交额5,000万不影响以中位数判断。T 戴帽时 U2/U3 不通过，T+1 摘帽且届时其他条件满足才恢复资格。

### R03 权益事件、前复权及账户连续性

伪代码：

```text
为历史 T 选择公开可知且截至 T 已生效的权益事件版本
构建原始价格到 T 基准的前复权视图
同一基准内计算全部窗口、ATR、止损、入场参考价及 HC
切换基准时：价格型状态按 a×P+b 变换，距离型状态按 a×d 变换
持股数只按实际到账股份变动；现金只在实际到账日增加
取得权益但未到账：计入应收权益，不计入可买现金或可卖股数
权益事件缺字段、无法验证变换或不支持的事件：暂停受影响回测并列疑问
```

用例 A（纯拆股便于手算）：e 日买100股、价格20，S0=18，d=2；下一日1股变2股且全部到账，原始 K 线 `F(10)`。新基准下 P=10、S0=9、d=1、持股=200，股票市值仍2,000，初始风险仍200；不触发凭空50%的止损。

用例 B（现金分红）：登记日持100股、收盘10；除息日原始 `F(9)`，每股现金红利1元、后日到账。建议保守研究假设下计应收净现金80元，股票市值900元，总权益比除息前减少20元，来源为假设股息税；到账后应收减少80、现金增加80，权益不再增加。若今天下载的前复权历史从10改成9，不能再给前复权收益账户重复加100元分红。

股息税初版建议采用“应收时统一预留毛现金股息20%，不按实际持有期限退回”的保守研究假设，报告须写明这一点；它不是实际券商扣税规则。真实税收存在持有期限差异。[税务规则](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5203902/content.html) 如用户要求精确税后账本，需改为按持股批次及适用税制结算后再实现。配股选择、合并换股、复杂送股税务等未冻结事件不得自动用拆股模型代替。

### R04 时间可用性、枢轴确认与前缀一致性

伪代码：

```text
每次读取输入：断言公开时间 ≤ 当前允许时点，且适用生效时间满足要求
财务记录：按公开时间选当时版本，不按财报期末提前使用
枢轴高点：Hp 严格高于左侧 l 根及右侧 k 根全部 H 才成立
确认日期 = 第 p+k 根有效 K 线日期；最早执行 = 确认日期的下一市场交易日
完整数据限制至 T 的结果必须等于截断数据在 T 的结果
```

用例：有效 K 线依次为`[2,3,1,2]、[3,4,2,3]、[4,6,3,5]、[3,4,2,3]、[2,3,1,2]`，l=k=2，p=第3根。第5根收盘才确认高点6；最早第6根对应市场交易日开盘使用；不得第3或第4根交易。追加第6根高点100不能改写此前确认时点。季度净利润属于3月31日报告期、4月30日20:00公开：4月30日18:00的信号不可使用，下一适用信号日才可使用。本策略 A/B/C 不启用枢轴点，保留本用例作为将来扩展的防泄漏门槛。

### R05 SMA、TR 与 ATR

伪代码：

```text
SMA_n = 最近 n 个 C 的和 / n
TR_t = max(H_t−L_t, abs(H_t−C_prev), abs(L_t−C_prev))
ATR 首值 = 前 n 个可计算 TR 的平均；以后按 Wilder 平滑递推
不够窗口 = 不可计算；ATR ≤ 0 时禁止风险预算制新买入
```

用例：前收盘10，随后3根为 `[10,11,9,10]、[10,12,10,11]、[11,13,11,12]`。TR依次2、2、2；n=3时 ATR=2，SMA3=(10+11+12)/3=11。再加`[12,15,12,14]`，TR=3，新ATR=(2×2+3)/3=7/3。若连续平价且H=L=前收盘，则TR=0，不能除以0或自动给出满仓数量。

### R06 DM、DI、DX 与 ADX

伪代码：

```text
up = H_t−H_prev；down = L_prev−L_t
+DM = up，当 up > down 且 up > 0；否则为 0
−DM = down，当 down > up 且 down > 0；否则为 0
+DI = 100×Wilder(+DM)/ATR；−DI 同理；ATR=0 时两者置0
DX = 100×abs(+DI−−DI)/(+DI+−DI)；分母为0时置0
ADX 首值 = 前 n 个可计算 DX 的平均，随后 Wilder 递推
第一根K线没有 DM/TR；ADX_n 最少需要 2n 根K线
```

用例：n=3，6根为`[9,10,8,9]、[10,11,9,10]、[11,12,10,11]、[12,13,11,12]、[13,14,12,13]、[14,15,13,14]`。从第2根起TR=2、+DM=1、−DM=0；第4根首次得到ATR3=2、+DI=50、−DI=0、DX=100；第6根才得到首个ADX3=100。前根H=10、L=8，当前H=11、L=7时up=down=1，+DM=−DM=0，不得把扩张同时计入两个方向。

### R07 方案 A 的买入与趋势出场

伪代码：

```text
U = 当前根之前 55 根有效K线的最高 H
D = 当前根之前 20 根有效K线的最低 L
买入信号 = C_T > U 且 C_T > SMA120_T
趋势出场 = 持仓存在 且 C_T < D
买入只在无持仓、无持续退出意图、资格及冷却期通过时转为交易意图
```

用例用入场通道3、趋势SMA3、出场通道2代替生产窗口：此前3根`[9,10,8,9]、[10,11,9,10]、[10,10.5,9.5,10]`，T=`[10.5,12,10.4,11.5]`。U3=11，SMA3=10.5，11.5>11且>10.5，产生买入信号。若误含T，U会成为12并错过信号。把T收盘改成11，则等于上轨，不买。出场独立用例：前2根最低价9.8、10.1，T=`[10,10.2,9.6,9.7]`，9.7<9.8，产生趋势出场。

### R08 方案 B 的买入与趋势出场

伪代码：

```text
买入信号 = 前根SMA20 ≤ 前根SMA60 且 当前SMA20 > 当前SMA60 且 C > SMA60
趋势出场 = 持仓存在 且 SMA20 ≤ SMA60
若系统首次启动时已经处于SMA20>SMA60，不补造此前交叉买入
```

用例以SMA2/3代替20/60：依次`F(10)、F(9)、F(8)、F(11)`。第3根SMA2=8.5≤SMA3=9；第4根SMA2=9.5>SMA3=28/3，且11>28/3，触发买入。再加`F(7)、F(6)`，第5根SMA2=9>SMA3=26/3；第6根SMA2=6.5≤SMA3=8，触发趋势出场。若只加载第4根的指标状态，不知道前根交叉关系，则不给买入。

### R09 方案 C 的买入与趋势出场

伪代码：

```text
完整条件 = C>SMA60 且 SMA20>SMA60 且 ADX14≥25 且 +DI14>−DI14
买入信号 = 完整条件当前成立，前根不成立；前根未知不发事件
趋势出场 = (C连续2根低于各自SMA60) 或 (SMA20≤SMA60)
ADX下降或低于25不单独触发卖出
```

用例以SMA2/3、ADX2代替正式窗口：依次为`F(10)、F(9)、F(8)、F(9)、F(10)、F(11)`。从第2根起TR均为1。第3根首次得到+DI=0、−DI=100、DX=100；第4根+DI=50、−DI=50、DX=0，首次ADX2=(100+0)/2=50，但SMA2=8.5<SMA3=26/3，完整条件不成立。第5根+DI=75、−DI=25、DX=50、ADX2=50，SMA2=9.5>SMA3=9且C=10>9，完整条件由假变真，产生买入。第6根+DI=87.5、−DI=12.5、DX=75、ADX2=62.5，条件仍真，不重复产生交叉事件。这组K线可直接手算，不依赖预先注入ADX数值。

趋势出场手算：收盘序列`10、11、12、11、10.5`，均用`F(C)`展开。SMA3在末两根分别为34/3、33.5/3，两次收盘均低于对应SMA3，第二次产生出场；只出现第一次不以“连续2根”出场。另测ADX恰等于25时强度门槛通过、+DI恰等于−DI时方向门槛不通过。正式窗口的端到端验收不能只用短窗口用例替代。

### R10 初始止损：ATR 与固定比例互斥

伪代码：

```text
T日只记录 ATR_T、参考初始止损和拟买数量上限
T+1实际成交后：
  ATR方式：d = 2.5×ATR_T（先换到执行日基准）；S0 = P−d
  固定方式：d = 0.08×P；S0 = P−d
若 S0≤0 或 d≤0：取消新买入
持仓每个收盘：C≤等价转换后的S0 时触发初始止损
不以当天L触线模拟盘中卖出，不按S0保证成交
```

用例：T日ATR20=0.4，次日原始开盘与成交价均10（本用例滑点0），ATR方式d=1，S0=9；固定方式d=0.8，S0=9.2。持仓日`[9.3,9.5,8.8,9.1]`：ATR方式初始止损不触发，固定方式触发。次日开盘8.5且可成交，固定方式在8.5执行，不在9.2执行。初始止损建立后ATR上升至0.6，也不能把原S0=9放宽为8.5。

### R11 移动止盈与时间止损

伪代码：

```text
HC = max(同基准入场价、入场日至T的全部有效收盘价)
M_T = max(同基准S0、同基准M_prev、HC−3×ATR20_T)
移动止盈信号 = M_T>S0 且 C_T≤M_T
时间止损信号 = 已开启 且 h≥20 且 (HC−同基准入场价)/同基准d < 1
先在T收盘更新HC和M，再判断C；所有卖出都留到T+1
```

用例：P=10、d=1、S0=9，历史最高收盘HC=12，T−1移动止盈10.5；T K线`[11.2,11.3,10.3,10.4]`、ATR=0.6，HC−3ATR=10.2，所以M保持10.5不降，C=10.4触发移动止盈。M只是出场参考线，不保证盈利。

时间用例：P=10、d=1，前19个市场交易日收盘均10.5，第20日`F(10.9)`，HC=10.9，MFE_R=0.9；开启时间止损时触发，关闭时不触发。第20日改为`F(11)`，MFE_R=1，不触发；第20日官方停牌且此前HC=10.9时仍产生时间退出意图，执行受停牌阻断。

### R12 大盘状态与总仓位目标

伪代码：

```text
若指数及SMA200、20个市场交易日前SMA200不完整：状态=未知
否则若指数C>SMA200 且 SMA200>SMA200_lag20：状态=牛，目标80%
否则若指数C<SMA200 且 SMA200<SMA200_lag20：状态=熊，目标0%
否则：状态=震荡，目标30%
目标下降且实际W>新目标，或W>目标+5个百分点，或目标0且W>0：
  生成大盘减仓意图，按R16顺序选择完整持仓，直到计划卖出后W≤目标
其他情况只控制新买入；不因目标提高而强制买满
```

用例缩短为SMA3及滞后1：指数`F(10)、F(10)、F(10)、F(12)`，末日SMA=32/3、前日SMA=10，C=12，牛。序列`10、10、10、8`为熊；`10、10、10、10`为震荡，相等不判牛或熊。账户权益10万、股票市值8万，状态牛转震荡后计划卖出至少5万市值；若持仓每只1万，则卖出5只。因跌停实际只卖出3只时W仍50%，不能在看板伪装成30%。

### R13 买入排序、持仓唯一性与冷却期

伪代码：

```text
拒绝已有持仓、持续退出意图、尚未结束冷却期的同票新买入
符合资格且产生买入信号的股票，以Z降序、股票身份升序排序
排序只使用T数据，生成一次固定候选序列
全卖出日记为x，x之后满5个市场交易日的收盘才允许新信号转订单
单票不加仓、不摊平；首日启动不自动补齐既有趋势持仓
```

用例：甲`F(12)`、SMA60=10、ATR=1，Z=2；乙`F(11)`、SMA60=10、ATR=0.5，Z=2；丙`F(11)`、SMA60=10、ATR=1，Z=1。甲乙按股票身份升序，再丙。甲已持仓则不新增。x日卖出，x+1至x+4收盘的新信号不能转订单；x+5收盘冷却结束，可计划x+6买入。次日丙大涨也不能据此调到前面。

### R14 单票数量、风险和现金约束

伪代码：

```text
T日参考价格P_ref=Craw_T；按选定初始止损方式求参考距离d_ref
T日先建立计划账本：将拟全卖持仓按T收盘价估计退出，估计所得扣预计费用
在计划账本中预留可释放的现金、持仓名额和初始风险额度，不修改实际账户
风险方式原始数量 = floor(r×E_T/d_ref)
等权方式原始数量 = floor(0.10×E_T/P_ref)
两种方式均再受以下约束：
  单票计划风险≤r×E_T；单次建仓市值≤0.10×E_T；最多10只
  组合剩余初始风险额度加新订单风险≤0.04×E_T
  已有及已分配新仓市值≤大盘目标×E_T
  买入价款及买入费用≤可用现金
  新订单参考成交额≤截至T的最近20个市场交易日成交额中位数×0.001
按板块数量规则向下取整；不足最小数量则放弃，不向上凑足
T+1卖出尝试完成后，使用实际剩余现金/持仓/风险重新约束买入，只可缩量或取消
T+1按开盘执行价格计算d和金额，不增加T日数量上限
风险预算与单次建仓金额上限继续使用冻结的E_T，不因开盘上涨提高预算
总仓位另按拟成交后的开盘估值权益重新检查，含拟交易费用与滑点影响
只有拟成交后的总仓位仍不超过T确定的大盘目标，才允许新买入
```

0.001 的成交额比例只是基于历史成交额的保守订单规模门槛，不能代表开盘可成交量，也不能使用 T+1 全天成交量来反算开盘数量。平仓不受这一买入规模门槛限制。T日计划中的卖出未在T+1成交时，不能获得计划释放的现金、名额或风险额度；后面的买入要相应缩量或取消。价格上涨使既有单票市值超过10%时只提醒，不主动把既有持仓每日恢复等权；10%是新建仓时以信号日权益衡量的金额上限。当前实际风险比例和当前实际总仓位另外展示，可能因价格变化或无法退出而超标。

用例：E=100,000，P_ref=10、ATR=0.4，d=1，r=0.5%；风险方式得500股、市值5,000、计划风险500；10%市值上限为1,000股，因此不截断500。等权目标1,000股，但同一风险上限把它截到500股。若P_ref=100、ATR=4，则风险数量50股，不足主板100股，放弃，不买100股。股票K线分别取`F(10)`或`F(100)`，ATR历史作为已验证输入。

执行缩量用例：T上限500股，次日开盘10.20，固定比例方式d=0.816，每票风险上限仍500元；即使理论风险可容许612股，也不能超过500。现金仅4,100元，则最多买400股；现金扣除后必须非负。卖出受阻用例：T时现金0、拟卖持仓按`F(10)`估计可收回5,000元，计划新买入500股×10元；T+1旧仓开盘跌停未售出，则实际现金仍0，新买入取消。

上述“执行缩量用例”与“卖出受阻用例”必须实现为第二步验收的必过单元测试，不是说明性示例；另须覆盖“计划账本释放的现金、名额与风险额度在卖出未成交时不生效”的断言。

不在本文凭空补齐历史首日上市、重新上市、退市整理首日、早期创业板等全部例外。第一阶段必须形成覆盖用户所选板块及区间的制度表；这类**外部制度待核实清单**不允许实现者用通用比例代填。

### R17 T+1 开盘执行、跳空与无法成交

伪代码：

```text
输入仅为T冻结的交易意图、执行前已公开状态、执行日官方开盘及价格限制
先卖后买；只把已模拟成交的卖出所得计入可买现金
新买入再次核验执行日ST/退市/板块权限；不再符合所选U方案时取消
这一复核只减少已有意图，不用隔夜新信息新增T日信号或提高买入资格
若停牌、没有可核验开盘或缺少制度：不成交，记录原因
买入：若开盘≥涨停价，则取消；若开盘≤跌停价，也保守取消新买入
卖出：若开盘≤跌停价，则受阻；开盘涨停可卖
买入：若开盘−同基准C_T > 同基准ATR_T，取消，不追更大的向上跳空
买入：若开盘≤T日参考初始止损的等价转换值，取消
滑点拟成交价：买=Oraw×(1+s)，卖=Oraw×(1−s)
买价向上、卖价向下按最小价位舍入；不越过当日官方可交易边界
按R14只缩量，满足资金、风险、仓位、数量约束后成交
未成交买入到T+1开盘尝试后失效，不在盘中补买
未成交卖出保留剩余数量，下一市场交易日继续尝试
```

边界限制指：在未触发开盘封板阻断的前提下，滑点拟成交价买入不高于涨停价、卖出不低于跌停价；无涨跌幅限制日不裁剪到虚构涨跌停价。不得用 T+1 当天 H/L 来裁剪成交价。该价格是日线研究模型的保守成本代理，可能不等于真实开盘集合竞价成交价；真实账户以回报为准。

用例 A：T收盘10、ATR0.4、买入500股，T+1涨停11，K线`F(11)`，买入失败、现金不变、买单失效。T+1改为`[11,11,10.5,10.8]`，即使后来开板，开盘仍11，仍不买。

用例 B：已有100股、已发退出，次日跌停9，K线`F(9)`，卖出失败；再一日跌停8.1、K线`F(8.1)`，继续失败；第三日价格限制7.29～8.91、开盘8.3，K线`[8.3,8.5,8,8.2]`，滑点0时在8.3成交。不能在前两天止损价9.5成交。

用例 C：T收盘10、ATR0.4，次日开盘10.5，向上跳空0.5>0.4，取消。开盘10.4恰等于1ATR则通过跳空门槛。若T参考止损9、次日开盘8.9，即便当日无价格限制也取消新买入。

开盘后人工看见价格再下单，不能保证成交在原始开盘价。工作台显示“开盘执行模型价”和“真实成交价”两个字段。若用户希望严格模拟开盘后若干分钟的人工交易，需要另行确认分钟数据口径，不暗中声称日线已做到。

### R18 费用与滑点记账

伪代码：

```text
金额 = 已模拟成交价×实际成交股数
佣金 = max(金额×0.0003, 5元)，每只股票每次买/卖意图的实际成交分别计
印花税 = 卖出金额×适用日期税率；买入为0
过户费 = 金额×适用日期费率，买卖均计
每项费用四舍五入到分；未成交费用为0
买入现金减少=金额+佣金+过户费
卖出现金增加=金额−佣金−印花税−过户费
滑点已进入成交价，不能再扣一次“滑点费用”
```

用例费用按2026普通A股、滑点0：买1,000股×10元，金额10,000，佣金max(3,5)=5，过户费0.10，现金减少10,005.10。卖1,000股×11元，金额11,000，佣金5，印花税5.50，过户费0.11，现金增加10,989.39。两次K线分别`F(10)`、`F(11)`，该完整交易净盈利984.29元。

滑点单独用例：原始开盘10，5bp；买入理论10.005，向上到0.01元为10.01；卖出理论9.995，向下为9.99。费用据10.01／9.99的成交金额重新计算，不与前一个滑点0用例混用。小价格股票因最小价位可能承受高于5bp的实际模拟滑点。

### R19 T+1 可卖数量与退出意图状态

```text

同日买入不可同日卖出；当日收盘发出的退出最早下一交易日执行
```

### R21 绩效计算

伪代码：

```text
只在预热结束后的评价日记录 r_t=E_t/E_prev−1，连续保留空仓日及停牌日
CAGR=(E_end/E_start)^(252/n)−1
MDD=max(1−N_t/截至t最高N，最高值包含N_0=1)
胜率=盈利完整交易数/完整交易总数
盈亏比=平均盈利金额/平均亏损金额绝对值
累计换手=sum((买额+卖额)/(2×前日权益))
年化换手=累计换手×252/n
卡玛比=CAGR/MDD；MDD=0时为不可定义，不输出无穷好成绩
无完整交易时胜率不可定义；缺盈利或亏损组时盈亏比不可定义
```

用例：为单独核对净值，设无费用的10股持仓、无现金，合成收盘依次`10、11、8.8、9.68`，各取`F(C)`，这些是指标测试价格，不启用涨跌幅撮合。权益`100、110、88、96.8`，日收益10%、−20%、10%，MDD=20%，评价n=3，CAGR=0.968^(252/3)−1≈−93.49%，卡玛≈−4.67；短样本年化仅用于公式验收，报告不拿它推测未来。另有完整交易盈亏`+100、−50、0`，胜率1/3，盈亏比2。某日买额10,000、卖额20,000、前日权益100,000，日换手15%。

### 5.1 费用默认假设与历史日期

| 滑点 | 买卖每边5bp，再按不利方向舍入最小价位 | 比较0/5/10/20bp四个情景；成交边界与舍入规则不变 |
| 现金收益 | 0 | 不模拟逆回购、利息或现金管理收益 |
| 其他资金成本 | 0 | 自有资金、无融资融券；不把未借入资金计算融资费 |

印花税减半的生效日期来自财政部、税务总局公告。过户费调整有中国结算公告的新华社报道，当前费率可与提供相关交易服务的机构收费文件交叉核对。后者包含跨境服务的其他费用，本文只引用其中中国结算这一费用项目，不把跨境附加收费套用于境内账户。[印花税公告](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5211343/content.html)、[中国结算调整公告报道](https://www.news.cn/fortune/2022-04/28/c_1128605983.htm)、[中国结算费用交叉核对](https://en.chinastock.com.hk/uploads/20220429112511_743194.pdf)

费用表是本次核查的制度基线；第一阶段仍须把用户实际佣金与所选历史区间完整制度覆盖写入验收记录。0.03%佣金、最低5元和5bp滑点不是全体券商的统一报价。

### 5.2 开盘模型的能力边界

采用R17保守开盘门槛后，一字涨停不能买、一字跌停不能卖，也不靠当天是否开板来事后决定开盘能否成交。普通开盘价内部的排队、真实开盘可成交量和人工延迟无法仅由日线精确重建。日线研究模型成交，不等于用户一定能获得同价同量成交。

T冻结数量、T+1价格超限时缩量，以及同日先卖后买，属于明确的日线模型假设，不是交易所集合竞价的逐笔仿真。若希望严格在集合竞价前一次性提交固定股数，需另选“前日预留现金、不使用同日卖出所得、固定股数超限取消”模型，经用户确认后替换，不能混用二者结果。

回测中T+1无买入信号时不新建仓；期末未平仓按最后完整交易日收盘估值，保留未实现盈亏，不虚构期末卖出及费用。另列期末潜在退出费用情景可以，但不得混入主报告。

### 5.3 预热、区间及样本划分

在推荐配置下，个股至少需要SMA120、U55、D20、ATR20、SMA60所需的完整历史；指数SMA200及滞后20至少需要220根完整日线。历史有停牌时不能只取固定120个自然日。ADX若启用，按R06初始化，不依赖库默认的隐藏预热。

评价期开始时账户为空、现金为确认的起始资金；预热期间不产生评价期持仓。首个评价日开盘可执行前一交易日收盘计算的信号，但该前一日仅用于初始化计划，不计入评价收益；不存在信号时继续空仓。首次运行B/C遇到此前早已成立且没有新交叉的条件，不补造买入。

建议按完整可用评价交易日的前60%／中20%／后20%划分样本内、验证段、样本外；取整分别向下，剩余日期归最后一段，实际边界写入报告。指标可以使用前段历史预热，但样本外参数冻结。主回测资金连续运行，分段报告标注期初承接持仓；另做各段空仓启动对照时独立标识，不能混报。数据覆盖不足、缺少主要市场状态或完整交易很少时，不据此选优。
