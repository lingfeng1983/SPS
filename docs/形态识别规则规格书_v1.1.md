# 形态识别规则规格书 V1.1

> 用途：牛股识别系统·形态识别引擎的精确数学定义。所有阈值均为初始参数，后续用历史回测校准。
> 适用范围：A股日线数据（前复权），月线形态另注。
> 版本原则：任何参数校准只允许使用训练区间；报告必须同时给出样本外结果，禁止用全样本调参后再把全样本结果称为回测表现。

---

## 0. 通用约定

### 0.1 数据与符号

| 符号 | 含义 |
|---|---|
| `O,H,L,C,V` | 开盘价/最高价/最低价/收盘价/成交量 |
| `C[t-n]` | 相对交易日 t 的 n 个交易日前收盘价；`C[t]` 为当日收盘价 |
| `C[t+n]` | 相对交易日 t 的 n 个交易日后收盘价，仅用于信号发生后的统计 |
| `MA(n,t)` | 截至 t 日（含 t）的 n 日简单移动平均；需要避免当日数据时明确写 `MA(n,t-1)` |
| `ATR(n,t)` | 截至 t 日的 n 日 Wilder ATR，单位为价格，默认 n=14 |
| `NATR(n,t)` | `ATR(n,t) / C[t]`，单位为比例 |
| `Vol_MA(n,t-1)` | t 日之前 n 个有效交易日的成交量均值，不含 t 日 |
| `RPS(n)` | 相对强度排名（n 日涨幅在全市场的百分位），欧奈尔体系建议 ≥85 |

价格百分比与 ATR 是两种不同单位，不得直接混写。规则中的 `%` 均以对应基准价计算；`x×ATR` 均为价格距离。需要转成比例时使用 `NATR`。

### 0.1.1 时间、复权与样本可得性

- 所有窗口均按**交易日**计算。停牌日不补零成交量，也不合成K线。
- 形态几何、均线和收益统一使用同一套前复权 OHLC；成交量使用原始成交量。涉及真实跳空、涨跌停和成交可执行性时，必须同时读取不复权 OHLC，避免除权除息产生伪缺口。
- RPS 和全市场排名必须使用当日真实可见的历史股票池，包含后来退市股票，禁止用当前股票列表回填历史（幸存者偏差）。上市不足 n 个交易日的股票，其 `RPS(n)` 记为缺失，不参与该规则。
- 财务、股东户数等非行情数据按实际披露日生效，禁止按报告期结束日提前使用。
- 默认排除信号日上市未满 120 个交易日、当日停牌、退市整理期股票；是否排除 ST/`*ST` 必须作为回测配置并分层报告。

### 0.2 摆动点（Pivot / Zigzag）——几何形态的基础

- **摆动高点**：某日 H 高于其前后各 k=5 根K线的最高价（即局部极大值）
- **摆动低点**：对称定义
- k 为灵敏度参数：k=3~5 用于短线形态，k=8~10 用于基底类大形态
- 由摆动点序列 `P1,P2,P3...` 构造高低点折线，作为三角形/楔形/头肩等的输入
- **可用时点**：位于交易日 p 的摆动点，最早只能在 `p+k` 日收盘后被确认。扫描与回测不得在 `p+k` 之前使用该摆动点，否则构成未来数据泄漏。
- **近似水平判定**：两点价差 ≤ `min(2% × 两点均价, 1×ATR(14,较晚点))`。这是严格口径；宽松口径可改为 `max`，但必须使用不同参数版本号，禁止混样本。
- **趋势线拟合**：2 点只生成候选边界；至少 3 个同类型摆动点才能确认边界，并对全部点做最小二乘回归。每个点到拟合线的垂直价格偏差须在 ±1×该点 ATR 内，且记录拟合 R²。
- 几何形态默认使用 `k=5`；杯柄、圆弧底、月线基底等跨度 ≥60 日的形态默认 `k=8`；旗形和 K 线辅助形态默认 `k=3`。k 是版本化参数，不能在同一回测中事后择优。

### 0.3 确认日（Signal Day）与失效（Invalidation）

- 每个形态必须定义**确认条件**，只有确认才产生信号；未确认只算"候选形态"
- 确认日 t 的收盘价只作为**理论信号价**。因为确认依赖 t 日收盘价和成交量，主要可执行回测统一使用 t+1 日开盘价；确认日收盘成交仅作为辅助上界统计，不得称为可执行收益。
- 若 t+1 停牌、开盘一字涨停或无可成交价格，则按统一执行模型顺延至首个可成交日，最多顺延 5 个交易日；仍不可成交则记为“未成交信号”，不得从胜率分母中静默删除。
- **失效规则（通用）**：确认后收盘价跌破各形态关键位，或收盘价 `< A - 2×ATR(14,t)`，形态作废并记入统计。A 为对应版本的实际进场价；ATR 固定取信号日数值，避免阈值随行情漂移。

### 0.4 成交量约定

- `VR20(t) = V[t] / Vol_MA(20,t-1)`；未特别注明时，本文“量比”一律指 `VR20`。
- `VR5(t) = V[t] / Vol_MA(5,t-1)`，仅在规则明确写 `VR5` 时使用。
- 放量：`VR20 > 1.5`；显著放量：`VR20 > 2.0`；缩量：`VR20 < 0.7`。
- 对停牌复牌、除权、成交单位变化等异常日须打数据质量标签；成交量均值只使用此前有效交易日。

### 0.5 通用定量词典

- **上升趋势**：`C[t] > MA(60,t)` 且 `MA(60,t) > MA(60,t-20)`；下跌趋势取反。规则若使用 MA20 等其他周期，会明确写出。
- **大阳线**：`C>O`、当日实体 `C-O` ≥ 此前 20 日实体绝对值中位数的 1.5 倍，且 `C/C[t-1]-1 ≥ 2%`。
- **量能逐步萎缩**：对形态区间的 `log(V)` 按时间做线性回归，斜率 <0，且最后 5 个有效交易日日均量 ≤ 最初 5 日均量的 80%。
- **放量阳线**：`C>O` 且 `VR20≥1.5`。周线规则中的量比另定义为 `WVR10 = 本周成交量 / 此前10个完整周的周均成交量`。
- **突破**：除非形态另有缓冲，均指确认日收盘价严格大于使用确认日前数据得到的边界价；相等不算突破。
- 形态中的所有“一段上涨/下跌”必须能由已确认 Pivot 确定起止点；若找不到符合窗口的 Pivot，规则不命中。

## 一、结构类形态（基于 Pivot 几何）

### 1.1 双重底（W底 / Double Bottom）

**结构要求**
- 两个摆动低点 L1、L2：
  - 价差 `|L1−L2| / ((L1+L2)/2) ≤ 3%`（允许右底略高，右底更低视为弱势版本单独标注）
  - 间隔 T ∈ [15, 90] 个交易日
  - 中间反弹高点 M：相对 `min(L1,L2)` 的反弹幅度 ≥15%，且价格距离 ≥ `2×ATR(14,M日)`
- 第二个底的构筑时间 ≥5 个交易日：以 L2 为中心、价格处于 `L2+1×ATR(14,L2日)` 以内的有效交易日至少 5 日，排除一天插针。
- 第二底量能取 L2 前后各 2 日的日均量；须低于 L1 同口径日均量。因摆动点确认有 k 日延迟，这一窗口在信号前必须已经完整可见。

**确认条件**
- 收盘价突破中间高点 M（颈线）
- 突破日放量：`VR20 ≥ 1.8`

**关键位**
- 止损参考：`L2 − 1×ATR(14,确认日)`
- 失效：确认后收盘价 `< M − 1×ATR(14,确认日)`；“仅跌回 M 下方”不单独判失效。

**输出标签**：`W_BOTTOM`，附字段：右底是否更高（stronger）、双底间隔天数

---

### 1.2 三重底（Triple Bottom）

- 三个低点 L1≈L2≈L3，两两价差除以对应两点均价均 ≤3%
- 总跨度 ∈ [30, 180] 交易日
- 中间两次反弹幅度相近：两次反弹幅度之差除以两者均值 ≤25%
- 第三底按“双重底”的 ±2 日窗口口径缩量，且日均量低于前两底日均量的均值
- 确认：收盘价突破两个中间反弹高点形成的阻力线，且 `VR20 ≥ 2`
- 标签：`TRIPLE_BOTTOM`

---

### 1.3 头肩底（Head & Shoulders Bottom）

**结构要求**（低点序列 S1-H-S2，H 为头；反弹高点 N1、N2 位于相邻低点之间）：
- H < S1 且 H < S2（头部最低）
- 两肩大致对称：`|S1−S2| / ((S1+S2)/2) ≤ 5%`；两肩到头的横向距离比 ∈ [0.6, 1.6]
- 颈线 = N1、N2 连线（可为上斜/下斜/水平），确认日使用该直线在当日的价格，不得把未来点加入拟合
- 右肩区间日均量 ≤ 左肩同长度区间日均量的 70%

**确认条件**
- 收盘价突破颈线 + `VR20 ≥ 1.8`
- （可选增强）突破后回踩颈线不破再上涨——二次确认版单独标注

**关键位**：止损 = `S2 − 1×ATR(14,确认日)`；目标参考位（仅供报告展示，不进统计）：确认日颈线价 + 头到颈线的垂直距离

标签：`HS_BOTTOM`

---

### 1.4 杯柄形态（Cup with Handle）

欧奈尔核心形态，参数按其著作设定：

**杯体要求**
- 左侧杯沿高点 H_top 之前 20~120 个交易日内存在已确认摆动低点 P，且 `H_top/P−1 ≥30%`
- 杯深（H_top 到杯底）：12% ~ 33%（熊市环境放宽到 ≤50%，单独标注）
- 杯体时长 ≥ 35 个交易日（约 7 周），典型 3~6 个月，上限 250 日
- 杯底形状偏 U 型而非 V 型：杯底区域（最低价 ±3%）滞留 ≥ 10 个交易日，或用二阶拟合检验圆弧度（杯底附近斜率渐变）
- 杯右沿回升至距左沿高点 10% 以内；≤5% 标记为 `tight_rim=true`

**柄部要求**
- 柄长 5 ~ 20 个交易日
- 柄回调深度 ≤ 杯深的 1/2，且绝对深度 ≤ 12%
- 柄的低点不低于杯体中点位置（否则是失败形态）
- 柄部缩量（末期 Vol_MA5 < 杯内均量的 70%）
- 对柄区收盘价做线性回归：斜率 ≤0 为标准柄；斜率 >0 标记 `weak_handle=true` 并降级，但仍保留为候选

**确认条件**
- 收盘价突破柄的上边界（buy point = 确认日前柄区最高价），且 `VR20 ≥ 2`，同时当日成交量 ≥ 柄区此前日均量的 1.4 倍；两项必须同时满足
- 最佳买点区域 = 突破价上方 5% 以内（超过 5% 属于追高，报告标注 extended）

**关键位**：止损 = 突破价 × 0.93（欧奈尔 7~8% 规则）

标签：`CUP_HANDLE`，附字段：杯深、杯长、柄深、是否强势柄

---

### 1.5 平台突破（Flat Base Breakout）

- 横盘区间：≥ N=20 个交易日（上限 60 日），区间振幅（最高H−最低L）/最低L ≤ 15%（牛股平台更紧，≤10% 单独标注 strong）
- 区间内至少有一次缩量回调（Vol_MA5 曾低于 Vol_MA20 的 80%）——洗盘特征
- 平台开始前 20~120 日内须存在由已确认 Pivot 构成的上涨段；平台内最大回撤不超过该上涨段价差的 25%
- RPS(50) ≥ 85（横盘期间相对强度不弱，这是欧奈尔平台的关键：抗跌）

**确认条件**
- 收盘价突破平台上沿（+0.1×ATR 缓冲防假突破）+ 量比 ≥ 2
- 若突破日相对前一日真实最高价形成 ≥2% 的向上缺口，标记为跳空突破（gap breakout）；不要求突破前一日为大阳线

**关键位**：止损 = 平台中轴 或 突破价 × 0.93

标签：`FLAT_BREAKOUT`

---

### 1.6 上升三角形（Ascending Triangle）

- ≥ 2 个近似水平的摆动高点 → 阻力线（斜率绝对值 ≤ 0.1×ATR/日）
- ≥ 2 个逐级抬高的摆动低点 → 支撑线（斜率 > 0，且与阻力线收敛）
- 至少 4 个摆动点，总时长 ∈ [20, 120] 交易日
- 形态过程中成交量满足 0.5 节“量能逐步萎缩”
- 低点抬高幅度递减（收敛）加分

**确认条件**：收盘突破阻力线 + `VR20 ≥ 1.8`。以形态起点至两边界理论交点为 0%~100%，突破发生在 50%~75% 区间为标准；>75% 降级，达到或超过 100% 不再视为三角形突破。

标签：`ASC_TRIANGLE`

---

### 1.7 下降楔形（Falling Wedge，看涨版）

- 高点和低点同时下移：两条边界斜率均为负
- 收敛：支撑线斜率绝对值 < 阻力线斜率绝对值（下边更平 → 会向上突破）
- 时长 ∈ [20, 120] 交易日，波动幅度逐段收窄
- 全程量能萎缩
- 位置分类：确认日前为 0.5 节上升趋势则记 `continuation`；为下跌趋势且楔形末端收盘较形态起点下跌 ≥10% 则记 `reversal`；其余记 `unclear` 并降级

**确认条件**：收盘突破上边界 + 量比 ≥ 1.5（楔形突破量能要求略低）

标签：`FALLING_WEDGE_BULL`

---

### 1.8 看涨旗形（Bull Flag）

- **旗杆**：之前 5~20 个交易日累计涨幅 ≥20%，其中至少 2 天同时满足 0.5 节“大阳线”且 `VR20≥1.5`
- **旗面**：随后 5~15 个交易日的回调通道：
  - 回撤幅度 ≤ 旗杆涨幅的 1/3（理想 10%~25%）
  - 通道向下或水平倾斜（角度 < 45°向下）
  - 旗面内量能显著萎缩（末期均量 < 旗杆期均量的 50%）
- 不破旗面下沿

**确认条件**：收盘突破旗面上沿 + 量比回升至 ≥ 1.5

标签：`BULL_FLAG`

---

### 1.9 看涨对称三角形（Symmetrical Triangle）

- 高点降低 + 低点抬高，两条边界收敛
- 时长 [20, 120] 日，至少各 2 个高点和低点
- 方向中性，仅当确认日满足 0.5 节上升趋势才产生看涨信号
- 确认：向上突破上边界（发生在三角形宽度 1/2 ~ 3/4 处最佳）+ 量比 ≥ 1.8

标签：`SYM_TRIANGLE_BULL`

---

### 1.10 矩形箱体（Rectangle，上升趋势中继）

- ≥ 2 个等高摆动高点 + ≥ 2 个等深摆动低点，形成水平通道
- 通道宽度 5%~20%，时长 ≥ 15 日
- 仅在确认日满足 0.5 节上升趋势时看涨
- 确认：放量突破箱体上沿，量比 ≥ 2

标签：`RECTANGLE_BULL`

---

### 1.11 圆弧底（Rounding Bottom / Saucer）

- 用滑动窗口二次拟合：取 60~250 个交易日的窗口，将前复权收盘价转为以窗口首日为 1 的对数价格，并先做 5 日中位数平滑，再拟合二次曲线，要求：
  - 拟合优度 R² > 0.7
  - 二次项系数 >0；拟合顶点位于窗口横轴 1/3~2/3 区域，且拟合曲线在顶点左侧单调下降、右侧单调上升
  - 谷底两侧对称性：左右臂长度比 ∈ [0.6, 1.6]
- 全程无尖锐低点：谷底前后各 5 日内任一日真实振幅 `(H-L)/C[t-1]` 不得超过 `max(8%, 3×NATR(14,t))`
- 确认：价格突破圆弧右臂高点 + 量比 ≥ 1.5

标签：`ROUNDING_BOTTOM`

---

### 1.12 VCP（波动收缩形态，欧奈尔/Minervini）

- 从左侧高点起，经历 ≥ 2 轮（典型 2~4 轮）连续收缩的回调：
  - 每轮回调深度依次收窄：如 25% → 15% → 8%（后一轮 ≤ 前一轮 × 0.75）
  - 每轮之间由小幅反弹连接
  - 总时长 15~65 个交易日
  - 最后一轮回撤 ≤ 10%
- 整体量能逐轮萎缩，末段出现极度缩量日（< Vol_MA50 的 60%）
- Minervini 趋势模板作为加分项而非硬条件：`C>MA150>MA200`、MA200 至少连续 20 个交易日上行、C 高于 52 周低点至少 30%、且距 52 周高点不超过 25%。不得把“C ≥ MA200×1.3”误作标准条件。

**确认条件**：突破最后一轮回调高点 + 量比 ≥ 2

标签：`VCP`，附字段：收缩轮数、各轮深度序列

### 1.13 底部直升机（Base Helicopter / 直升机形态）

> 注：此名称在国内技术分析圈用法不一，本规格采用常见定义——**高位横盘后急速挖坑洗盘再快速收回**的形态（也称"黄金坑"）。若你指的是其他定义，实现时可调整。

> V1.1 决策：该名称缺乏统一、可核验的行业定义，暂列为**实验规则**，不得与标准结构形态合并统计；报告展示名固定为“黄金坑（结构义）”。

- 前提二选一：此前 20~120 日内存在 Pivot 上涨段且涨幅 ≥30%；或此前连续 ≥30 日区间振幅 ≤15% 且区间最低价距前 250 日最低价 ≤15%
- **挖坑**：3~10 个交易日内从坑口最高收盘到坑底最低收盘下跌 8%~20%，且满足以下之一：至少 1 日 `VR20≥2`；或至少连续 3 根阴线且三日成交量逐日下降
- **坑底停留** ≤ 5 个交易日
- **收坑**：坑底后 ≤10 个交易日收盘重新站上坑口价，收回日 `VR20≥1.5`
- 收坑后不回头（回踩不破坑口 −1×ATR）

**确认条件**：收盘站上坑口价 + 收坑过程量比 ≥ 1.8

标签：`GOLDEN_PIT`（黄金坑/直升机）

---

### 1.14 岛形反转（看涨岛型底）

- 左缺口：按不复权价格计算，孤岛首日最高价 `H[t] < L[t-1]`，缺口幅度 `(L[t-1]-H[t])/L[t-1] ≥ 1.5%`；随后 3 日内未回补
- 孤岛：缺口下方运行 3~15 个交易日
- 右缺口：按不复权价格计算，离岛日最低价 `L[u] > H[u-1]`，缺口幅度 `(L[u]-H[u-1])/H[u-1] ≥ 1.5%`，且当日 `VR20 ≥ 1.8`
- 右缺口 5 日内不回补则维持有效

**确认条件**：右缺口成立当日即为候选信号日并按次日可成交开盘价模拟；“5 日内不回补”是事后有效性标签，只能在 u+5 日后确认，不得用于回填 u 日选股。

标签：`ISLAND_REVERSAL_BULL`
除权除息日产生的机械缺口一律排除。

## 二、K线组合类形态（模板匹配）

> 短周期形态，胜率统计意义弱于结构形态，主要作为**辅助佐证信号**叠加在结构形态上。TA-Lib 已内置部分可直接调用（函数名列出）。

### 2.1 红三兵（Three White Soldiers，TA-Lib: CDL3WHITESOLDIERS）

- 连续 3 根阳线（C>O）
- 每根收盘价创新高：C[i] > C[i−1]
- 每根开盘位于前一实体内：O[i] > O[i−1] 且 O[i] < C[i−1]
- 实体要求：每根实体 ≥ 平均实体的 70%，上影线 ≤ 实体的 30%（排除长上影假阳线）
- 三根实体大小接近或递增；若第三根实体 < 第一根的 50% → 降级为"红三兵衰竭"，不算信号
- **增强过滤**：第三根收盘价距此前 60 日最低价 <20%，或三根 K 线位于已识别结构基底的后半段，才算看涨佐证；否则仅记录形态、不生成看涨佐证

标签：`RED_3_SOLDIERS`

### 2.2 看涨吞没（Bullish Engulfing，CDLENGULFING）

- 前一日阴线，当日阳线
- 当日 O ≤ 前日 C 且当日 C ≥ 前日 O（完全包住前实体）
- 当日成交量 > 前日
- 过滤：出现在支撑位（MA20/前低 ±1×ATR）附近才算有效信号

标签：`BULL_ENGULF`

### 2.3 启明星（Morning Star，CDLMORNINGSTAR）

- 三根K线：第一根为“大阴线”（0.5 节大阳线定义的镜像）→ 第二根跳空低开且实体 < 第一根实体 50% → 第三根满足 0.5 节大阳线并收复第一根实体 50% 以上
- 第三根 `VR20≥1.5`
- 第三根收盘价距此前 60 日最低价 <20% 才算看涨佐证

标签：`MORNING_STAR`

### 2.4 锤子线（Hammer，CDLHAMMER）

- 锤子：下影线 ≥ 实体 2 倍，上影线 ≤ 实体 10%，出现在下跌后
- 当实体为 0 时，上下影线比例规则不可计算，应归为十字线候选而非锤子
- 候选日次日阳线收于锤子实体上方后才确认；信号日为次日，不能回填到锤子出现日
标签：`HAMMER_CONFIRMED`

早晨十字星属于三根 K 线反转组合，单独使用 TA-Lib `CDLMORNINGDOJISTAR`，并沿用 2.3 的低位与第三根放量过滤；`CDLDOJISTAR` 只是十字星候选，不等同于早晨十字星。

标签：`MORNING_DOJI_STAR`

### 2.5 底部直升机（K线组合义，如用户所指为此义则用这条）

> V1.1 决策：与 1.13 一样列为实验规则，展示名固定为“底部直升机（K线义）”，两者永不合并样本。

- 长下影探底 + 快速拉回的 T 字/锤子结构，出现在长期底部（距 250 日低点 < 15%）
- 探底当日成交量为近 20 日最大（恐慌宣泄）
- 次日起 3 日内收复探底日开盘价

标签：`BOTTOM_HELICOPTER_CANDLE`
> ⚠️ 与 1.13 结构义的"直升机"区分开，报告中分别标注。

### 2.6 多方炮（两阳夹一阴）

- 阳线-阴线-阳线，中间阴线实体被两阳包住，第三根收盘高于第一根
- 第三根 `VR20≥1.5`
- 第三根 `C>MA20` 且 `MA20[t]>MA20[t-5]` 时有效

标签：`BULL_CANNON`

## 三、事件/状态类形态

### 3.1 口袋支点（Pocket Pivot）

欧奈尔派量化定义（Gil Morales & Chris Kacher 版本）：

- 前提：此前 15~65 日区间振幅 ≤25%，或满足 0.5 节上升趋势且当日距此前 20 日最高收盘回调不超过 15%；同时不得大幅偏离 MA10
- **核心条件**：某日上涨（C>O 且涨幅 >0），当日成交量 > 该日前 10 个交易日内所有“收盘价低于前收盘”的下跌日最大成交量；此前 10 日没有下跌日时不命中
- 该日收盘接近日内高点：当 `H>L` 时 `(H-C)/(H-L) ≤0.4`；`H=L` 时数据无效
- 当日涨幅 ≥ 2%（避免平庸小阳）
- 前提过滤：当日 `C > MA50`；`abs(C/MA10-1) ≤ 5%`（未过度延伸）；RPS(50) ≥ 85

**进场**：口袋支点日尾盘或次日开盘

标签：`POCKET_PIVOT`

### 3.2 月线反转（陶博士版）

月线级别状态转换，条件组合。所有月线条件只在月末最后一个交易日收盘后判定；盘中或未完成月份仅显示候选，不生成正式信号：

- **月线条件**：本月月线翻红（月收盘 > 月开盘），此前连续 ≥2 根月阴线，或月线 MA3 本月值 ≥ 上月值且上月值 < 上上月值
- 月收盘站上 10 月均线
- **周线条件**：最近一个完整周的周收盘站上 30 周均线，且该周收盘 > 周开盘、`WVR10 ≥1.5`
- **日线条件**：日线创 60 日新高
- **强度条件**：RPS(120) ≥ 87 且 RPS(250) ≥ 87
- 加分项：接近历史新高（距 52 周高点 < 15%）

**进场**：全部条件首次同时满足的月末信号日之后首个可成交日开盘

标签：`MONTHLY_REVERSAL`

### 3.3 52周新高突破（New High Breakout）

- 收盘价 `C[t] > max(C[t-250..t-1])` 才是正式突破；距前 250 日最高收盘 <1% 只标记为 `near_high` 候选，不产生 `NH_52W` 正式信号
- 强弱标签：此前 120 日内从任一滚动最高收盘到后续最低收盘的最大回撤 >25% 时标记 `weak=true`；“套牢盘”只作解释性描述，不作为可直接观测事实
- 确认：量比 ≥ 1.8

标签：`NH_52W`

### 3.4 突破缺口（Breakaway Gap）

- 按不复权价计算 `L[t] > H[t-1]` 且缺口幅度 `(L[t]-H[t-1])/H[t-1] ≥2%`；当日收盘还须突破一个已识别结构形态的平台上沿、颈线或其他关键位，不使用未定义的“密集成交区”
- 当日 `VR20≥2`
- 除权除息形成的机械缺口排除
- 3 日内不回补缺口是事后质量标签 `gap_holds_3d`，不能作为缺口日实时信号的已知条件
- 配合形态：缺口同时突破某个结构形态的关键位时，合并报告（如"杯柄+跳空突破"）

标签：`BREAKAWAY_GAP`

### 3.5 均线多头排列启动（Trend Initiation）

- `MA5 > MA10 > MA20 > MA60`，且 `MA60[t] > MA60[t-5]`，同时 `MA60[t-5] ≤ MA60[t-10]`
- 排列首次满足后的 10 个交易日内，首次出现 `C/C[t-1]-1 ≥2%` 且 `VR20≥1.5` 的交易日为确认日；10 日内没有确认则候选失效
- 本质是"阶段转换"信号（温斯坦第一阶段→第二阶段）

标签：`MA_BULL_INIT`

### 3.6 强势整理回踩（Pullback to Support，趋势跟随型）

- 趋势前提：MA60 向上、RPS(50) ≥ 85、C > MA60 持续 ≥ 60 日
- 回调触及 MA20 或 MA50 的 ±1×ATR 区域，触及日或其后 3 日内先出现缩量止跌（该日 `VR20<0.8` 且收盘不再创新低）
- 回调幅度 ≤ 前波涨幅的 38.2%（斐波那契）
- 确认：缩量止跌之后出现阳线，收盘重新站上 MA20 且 `VR20≥1.2`；“缩量止跌”和“放量确认”允许发生在不同交易日，避免同日条件自相矛盾

标签：`PULLBACK_SUPPORT`

### 3.7 MACD 底背离（Momentum Divergence）

- 价格创新低（L < 前一摆动低点对应价格），MACD DIF 不创新低（DIF > 前低点时 DIF）
- 两个低点间隔 ≥ 20 个交易日
- MACD 固定使用 12/26/9 参数；确认日满足 `DIF[t]>DEA[t]`、`DIF[t-1]≤DEA[t-1]` 且 `C[t]>O[t]`

标签：`MACD_DIV_BULL`
> 定位：辅助佐证信号，叠加于结构形态使用。

### 3.8 筹码集中信号（非图形，归入状态类备查）

- 股东户数连续 2 期下降且降幅合计 > 10%
- 户均持股金额上升 > 15%
- 配合任一结构形态时在证据卡中自动引用
- 每期数据从交易所或公司公告的实际披露日下一交易日起可用；若历史库没有披露时间戳，该信号不得进入回测，只能用于当前证据展示

标签：`CHIP_CONCENTRATE`

## 四、形态优先级与共现处理

同一股票同一时期可能命中多个形态，处理规则：

1. **层级排序**（大形态覆盖小形态）：
   `CUP_HANDLE/VCP > ROUNDING_BOTTOM/HS_BOTTOM/W_BOTTOM/TRIPLE_BOTTOM > FLAT_BREAKOUT/ASC_TRIANGLE/SYM_TRIANGLE_BULL/RECTANGLE_BULL/FALLING_WEDGE_BULL/BULL_FLAG > 事件状态类 > K线组合类 > 实验规则`
2. 层级仅用于报告展示，不代表已证明的收益强弱。同日多形态确认时，层级较高者为主形态；同层级依次按形态跨度更长、拟合质量更高、标签字典序确定，保证结果可重复。
3. 所有命中仍分别保留各自事件记录，主形态选择不得导致其他形态从各自统计样本中消失。
4. **共现分层**：结构形态 + 口袋支点 + 突破缺口三者共现的样本单独统计；在样本外证据出来前，只称“共现组合”，不得预设为“最强组合”。
5. K线组合类、MACD 背离和筹码集中永不作为独立买入信号，只作证据卡佐证项。1.13 与 2.5 的实验规则单独统计、单独展示。
6. 同一股票、同一标签在 20 个交易日内重复确认时，只保留首次事件用于主统计；后续事件记录为 `duplicate=true`。不同标签共现不去重。

## 五、统一统计口径（每个形态都要算）

| 项目 | 定义 |
|---|---|
| 进场价 A | 主口径为信号日后首个可成交日开盘价；确认日收盘价仅作理论辅助口径，两者不得混合汇总 |
| 胜率 P(n) | 从实际进场日 e 起，第 n 个交易日收盘 `C[e+n] > A` 的比例，n ∈ {5,10,20,60} |
| 平均/中位收益 | `(C[e+n]−A)/A` 的均值和中位数；同时报告 25%/75% 分位数和样本数 |
| MAE(n) | 进场后 n 日内最大不利偏移：`(min(L[e..e+n])−A)/A` |
| MFE(n) | 进场后 n 日内最大有利偏移：`(max(H[e..e+n])−A)/A` |
| 盈亏比 | 盈利样本平均收益 / `abs(亏损样本平均收益)`；分母为 0 时记为缺失 |
| 止损模拟 | -5%/-7%/-10% 三档。若开盘跳过止损价，按开盘价成交；盘中触发按止损价成交；一字跌停无法成交则顺延并记录滑点 |
| 成本后收益 | 扣除配置中明确的佣金、印花税、过户费与滑点；同时保留成本前结果。成本参数必须随回测报告输出 |
| 分层 | 仅用信号日可见数据判定：牛市（基准指数收盘 > MA200 且 MA200[t] > MA200[t-20]）/熊市（反向条件）/震荡（其余） |
| 年份分布 | 各年度样本数（检测形态近年是否失效）|
| 可执行性 | 总信号数、次日可成交数、顺延成交数、未成交数及各自比例 |
| 相对收益 | 相同持有期相对沪深300或配置基准的超额收益；基准代码随报告输出 |

**全市场扫描**使用逐日可得股票池并包含后来退市股票，样本期 ≥10 年。单一形态有效样本 <100 次时标注“样本不足”，不输出确定性结论。遇退市、长期停牌或持有期数据不足时，必须按预先定义的退出/删失规则计数并单列，禁止直接删除不利样本。

### 5.1 回测与校准约束

1. 时间序列至少拆分为训练集、验证集、最终样本外测试集；阈值和优先级只能在训练/验证集调整，最终测试集只运行一次。推荐再做滚动 walk-forward 稳健性检查。
2. 每次运行必须保存规则版本、参数哈希、数据版本/截止日、股票池版本、复权方式、代码提交号（如有）和随机种子（如有）。
3. Pivot 的 `p+k` 可用时点、月末确认、缺口持有标签、财务披露日必须经过自动化“无未来数据”测试。
4. 同一股票事件具有相关性。除逐事件统计外，至少提供按股票等权、按月份聚类的置信区间或 bootstrap 区间，不能把高度重叠事件当作完全独立样本。
5. 所有结果必须报告样本量、置信区间和未成交比例；“胜率高”不能替代收益分布、回撤和成本后期望。

## 六、V1.1 已落定的默认决策

1. “底部直升机”保留两个实验定义：1.13 `GOLDEN_PIT` 与 2.5 `BOTTOM_HELICOPTER_CANDLE`，永不混用或合并统计。
2. 月线反转暂以本文参数作为**项目内部基线规则**，不声称完整代表任何个人的唯一公开定义；`RPS≥87`、30 周线等全部外置为可版本化参数。
3. Pivot 默认值按 0.2 节执行：一般几何 k=5、长基底 k=8、短形态 k=3。
4. V1 只生成买入侧候选与信号；看跌形态留到独立的“持仓风险/退出规则”规格，避免把选股和持仓决策混成一个标签体系。

## 七、最小输出契约与验收标准

每条候选或确认事件至少输出：

```json
{
  "event_id": "sha256(symbol|pattern|signal_date|rule_version)",
  "symbol": "600000.SH",
  "pattern": "CUP_HANDLE",
  "status": "candidate|confirmed|invalidated",
  "pattern_start": "YYYY-MM-DD",
  "pattern_end": "YYYY-MM-DD",
  "signal_date": "YYYY-MM-DD|null",
  "available_at": "YYYY-MM-DD",
  "rule_version": "1.1",
  "params_hash": "...",
  "key_levels": {"breakout": 0.0, "invalidation": 0.0},
  "features": {},
  "co_patterns": [],
  "data_quality_flags": [],
  "duplicate": false
}
```

实现验收必须同时满足：

- 用合成 K 线为每个正式标签提供至少 1 个正例、1 个边界例和 1 个反例；
- 对 Pivot、月线、缺口和披露数据做逐日前推测试，证明当天输出不会因追加未来数据而改变历史的 `available_at` 以前状态；
- 相同数据、规则版本与参数重复运行，事件 ID、主形态和统计结果完全一致；
- 任一信号可回溯到使用的摆动点、阈值、关键位和成交量基准；
- 回测报告明确区分候选、确认、可成交、未成交、失效与删失样本。
